## メモ・仕様確認事項

### archive_queue.json の構造
```json
{
  "a3f1c2-9e04b7": "2026-02-27 14:32:01",
  "b1c2d3-e4f5a6": "2026-02-27 15:10:44"
}
```
- キー：SID
- 値：normalizer処理完了時刻（`Y-m-d H:i:s`）
- アーカイブ完了後にエントリ削除

### dispatcher_log.csv の形式
```
# 2026-02-27 14:32:01
timestamp,filename,card_id,result
2026-02-27 14:32:01,xxx.json,作品_キャラ_001,new
```
- バッチ実行ごとに `# 日時` 区切り行 + ヘッダー行
- result：`new` / `discard` / `merge`

### merge_editor / merge_builder の処理フロー
```
merge_group_list.json を読む
→ [HTML] 手動で差分確認・キー選択
→ [PHP] 新カード生成 → M_Confirmed/
        既存カード → mainDB_OLD/ 退避
        03b_merge/ 差分ファイル削除
        merge_group_list.json からエントリ削除
→ dispatcher（merge_confirmdゲート）が拾う
```

### work_editor（未実装）の処理フロー
```
work_viewer で作品内キーを横断確認
→ セル直接編集・値統一
→ 「編集完了」ボタン
→ 作品内全カードを新カードとして生成 → M_Confirmed/
   mainDB旧カード → mainDB_OLD/
→ dispatcher（merge_confirmdゲート）が拾う
```
